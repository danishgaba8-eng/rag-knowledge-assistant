# IT Security SOP

Harbor & Pine Logistics is a fictional company. This document is sample data for a demo.

## Passwords and sign-in

Passwords must be at least 14 characters long. Use the company password manager, VaultKey, to store them. Passwords are changed only when there is a suspected compromise, not on a fixed schedule.

Multi-factor authentication (MFA) is required for all company systems, including email, PeopleHub and Expensa.

## Phishing

If you receive a suspicious email, do not click links or open attachments. Use the "Report Phish" button in Outlook within 1 hour of receiving it. If you already clicked a link or entered credentials, call the IT Helpdesk immediately.

## Lost or stolen devices

Report a lost or stolen laptop or phone to the IT Helpdesk on extension 4400 within 2 hours. IT will lock and remotely wipe the device.

## Public networks

Always connect to the company VPN, SecureLink, before using public or hotel Wi-Fi.

## Software

Only install software from the Company Portal. Requests for other software go through the IT Helpdesk and need security review, which normally takes 3 working days.
